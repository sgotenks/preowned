# cards-model

Custom **cards** block. Purpose: grid of photo tiles, each showing a model name and availability count and linking to that model's results.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: image | category (comma-separated filter tokens, e.g. "v12, serie-speciali") | text (model name, "N disponibili", link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
