# hero-search

Custom **hero** block. Purpose: homepage hero photo with heading, intro and an inline car search form (country, model, location, results CTA, expand-search toggle).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image | text (heading, paragraph) | model placeholder | location placeholder | CTA link (results page URL + label) | countries (comma-separated, optional) | expand-search label (optional).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
