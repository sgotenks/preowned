# vehicle-details

Custom **tabs** block (vehicle-detail template). Purpose: detail tabs of the ad: optional equipment accordions, standard equipment list with "see all", technical key figures and spec accordions, dealer notes.

## Authoring

Model: `container`

Content: one row per group: tab | title | content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Consumption | `consumption` |

## Universal Editor fields

- Fields defined in `_vehicle-details.json`.
