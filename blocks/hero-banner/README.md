# hero-banner

Custom **hero** block. Purpose: page-opening background photo with a large title (text or logo image) and intro paragraph.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image (background) | text (title or logo image, paragraph).

## Supported variations

| Variation | Option class |
| --- | --- |
| Text Left | `text-left` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Text Left.
