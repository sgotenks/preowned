# vehicle-gallery

Custom **gallery** block (vehicle-detail template). Purpose: the ad photos: 2 large photos + 3 thumbnails and "+N" over a blurred backdrop (desktop), swipe slider with counter and thumbnail strip (mobile), fullscreen lightbox with grid and single views.

## Authoring

Model: `container`

Content: one row per photo: image.
