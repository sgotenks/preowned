# cards-teaser

Custom **cards** block. Purpose: grid of image + heading + text teasers, each with a "discover more" link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per teaser: image | text (heading, paragraph, link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
