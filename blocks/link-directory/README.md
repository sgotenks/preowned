# link-directory

Custom block. Purpose: centred groups of small links on a dark band (source SearchHints on the
results listings: dealers, models and countries), with a "show all" toggle for long groups.

## Authoring

Model: container `link-directory`, item `link-directory-group`.

One row per group: title | links (a bulleted list of links) | "show all" label (optional).
A group with more than 12 links shows the first 12 and a toggle that reveals the rest.

## Supported variations

No variations. Put the block in a `dark-grey` section for the source look.

## Universal Editor fields

- `title` (text), `links` (rich text list), `showAllLabel` (text).
