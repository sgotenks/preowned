# vehicle-summary

Custom **hero** block (vehicle-detail template). Purpose: the ad name, year / mileage / dealer line, price and contact button, with sticky top bar (desktop) and contact + call bar (mobile).

## Authoring

Model: `standalone`

Content: rows: text (heading + list) | price | cta (form link, tel link, #gallery, #vehicle-360 links).

## Universal Editor fields

- Fields defined in `_vehicle-summary.json`.
